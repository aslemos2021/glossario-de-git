# Objeto

Os objetos no Git (blobs, commits, trees e tags) são os blocos de construção armazenados na pasta .git/objects, onde cada arquivo vira um hash único. 
Por exemplo, ao rodar git hash-object -w arquivo.txt, o Git gera um ID como d670460 e salva o conteúdo do arquivo puramente como um objeto do tipo blob.
