# GitHub

GitHub é uma plataforma online que permite o salvamento de arquivos e diretórios na nuvem de forma a proporcionar uma visualização 
simples, intuitiva e prática.
O GitHub é muito utilizado para trabalhos colaborativos em empresas de software ou por desenvolvedores indie, devido ao fato de que
o GitHub permite a colaboração e junção do trabalho de múltiplas pessoas em um ambiente amigável e simples.
