# merge

O comando merge funde o histórico de duas branches no Git, unindo as alterações de um ramo na branch atual. Caso a mesma linha tenha sido modificada em ambas as branches, o Git gera um conflito de integração que deve ser resolvido manualmente.
Exemplo: o comando `git merge nome-da-branch` integra as alterações da branch especificada na branch ativa.
