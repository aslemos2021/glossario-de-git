# termo

Um repositório modelo é um repositório do GitHub que serve como base para a criação de novos projetos. Ele contém arquivos, pastas e configurações que podem ser reutilizados, facilitando a organização e economizando tempo.
Ao utilizar um repositório modelo, é possível criar um novo repositório com a mesma estrutura do original, sem precisar copiar os arquivos manualmente.
Esse recurso é útil para trabalhos em grupo e projetos que precisam seguir um padrão de organização.
