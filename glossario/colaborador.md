# Colaborador

Um colaborador é alguém que recebeu permissão direta do propietário
de um repositório para ler, clonar, criar ramificações (branches) e 
enviar alterações(push) de código diretamente prara o projeto principal.
Exemplo: O administrador acessa as configurações do repositório para convidar
oficialmente um colega de equipe, permitindo que ele execute git push 
origin main sem que suas alterações fiquem bloqueadas por falta de
privilégio.
