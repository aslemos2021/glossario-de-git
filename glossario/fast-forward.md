# fast-forward

 fast-forward é quando você vai juntar duas branches e uma delas está "atrás" da outra, sem nenhum commit novo no meio do caminho. Em vez de criar um commit de merge todo trabalhado, o Git só dá um pulo para frente e move o ponteiro direto pro último commit. É o jeito mais fácil de atualizar seu código, deixando o histórico retinho, limpo e sem curvas na linha do tempo.
